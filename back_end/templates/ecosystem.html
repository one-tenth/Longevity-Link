🔌 The Problem

現在的照護是破碎的：手錶一個 App、血壓計一個 App、家裡的監視器又是另一個 App。 長輩連遙控器都按不好了，你還期待他們管理 10 個物聯網裝置？

🚀 The Vision

CareMate 採用「無邊界模組化架構 (Boundless Modular API)」。我們不只是做 App，我們在打造照護界的 J.A.R.V.I.S.。

從今天的 Apple Watch，到明天的腦機介面 (BCI)；從控制燈光，到控制醫療機器人。只要有 API，我們就能接。 這是一個可無限擴充的生態系，因為未來的長輩，可能比你還 Cyberpunk。

開發者筆記：
目前已支援 RESTful API 與 MQTT 協定。雖然腦機介面還在畫大餅階段，但我們已經把 Interface 寫好了 (笑)。
