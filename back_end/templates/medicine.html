🚨 The Problem

許多長輩因視力退化或藥單資訊過於複雜，常有「吃錯藥」或「忘記吃藥」的風險。傳統的手動輸入排程既繁瑣又容易出錯。

💡 The Solution

我們利用 Generative AI 的強大語意理解能力，將非結構化的藥單照片，瞬間轉換為結構化的用藥排程。

使用者只需「拍一張照」，系統便能自動提取藥名、劑量、頻率及副作用，並自動設定手機提醒。

● Google Cloud Vision API (OCR)
● OpenAI GPT-4 Turbo (NLP)
● JSON Structure Parsing
